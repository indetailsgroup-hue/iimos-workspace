# คู่มือทดสอบ

ไฟล์ตัวอย่างภาษาไทย ใช้พิสูจน์ว่า extractor รักษาอักขระไทยและตรวจพบหัวข้อบท
บนเส้นทางไฟล์ที่มีทั้งช่องว่างและอักษรไทย ไม่ได้ใช้ทดสอบคุณภาพการสรุปเนื้อหา

บทที่ ๑ การเตรียมงาน

ระบุเป้าหมาย หลักฐานที่ยอมรับได้ และต้นทุนก่อนเริ่มงาน ห้ามรับแผนที่เกณฑ์สำเร็จ
ตรวจสอบด้วยคำสั่งไม่ได้

บทที่ ๒ การตรวจผล

รันคำสั่งตรวจซ้ำหลังแก้ไข แล้วอ่านผลทั้งหมดรวมถึง exit status ผลที่ถูกตัดทอน
